# 音效文件夹（随插件打包发布）

插件会读取这个目录里的 `.mp3`，用于点击、开关箱子等界面音效。

## 目录内容

本插件**自带** 5 个 Minecraft 游戏音效，开箱即用（总计约 60 KB）：

| 用途 | 文件名 | 大小 |
| --- | --- | --- |
| 点击（按钮 / 导航 / 任务卡片） | `ui-stonecutter-select_recipe-1.mp3` | 5.4 KB |
| 打开（控制台展开 / 弹窗打开 / 开关打开） | `block-chest-open-1.mp3` | 9.6 KB |
| 关闭（控制台收起 / 弹窗关闭 / 开关关闭） | `block-chest-close-1.mp3` | 10.8 KB |
| 成功 / 成就达成 / 升级 | `entity-firework_rocket-launch-1.mp3` | 27.2 KB |
| 出错 | `block-wooden_door-open-1.mp3` | 6.6 KB |

`hover`（悬停极轻的一下）不采样，由 WebAudio 现场合成，免得划过列表时太吵。

## 缺失时的行为

某个文件缺失时，**只有那一个音效**退回合成音（WebAudio 现场合成）：

| 缺失的音效 | 兜底合成音 |
| --- | --- |
| click | 28 ms 噪声瞬态 + 196→150 Hz 三角波，约 90 ms 木质轻叩 |
| open / close / toggle | 咔哒 + 两音上/下行，约 126 / 130 ms |
| success | C5-E5-G5 上行琶音，约 345 ms |
| levelUp | C5-G5-C6 上行琶音，约 355 ms |
| error | 130→98 Hz 三角波 + 低频噪声，约 205 ms |

每个音效最多打一条 `console.warn`，不会刷屏、也不会抛错。
