# 音效文件夹（不随插件发布）

插件会读取这个目录里的 `.mp3`，用于点击、开关箱子等 UI 音效。

## 为什么这里是空的

游戏内音效是 Mojang 的素材，**不能**随这个仓库一起发布，所以仓库里只有这份说明。
如果这里没有任何样本，插件会自动退回**合成音效**（WebAudio 现场合成，无需文件），
界面依旧有声音，只是不如原版样本好听。

## 想用原版样本

把你**自己拥有**的样本按下面的文件名放进这个目录（名字可以改，但要同步改
`src/30-audio.js` 顶部的 `MC_SAMPLE_NAMES` 映射），然后 `Ctrl + R` 刷新页面：

| 用途 | 建议文件名 |
| --- | --- |
| 点击 | `ui-stonecutter-select_recipe-1.mp3` |
| 打开（控制台展开 / 弹窗打开） | `block-chest-open-1.mp3` |
| 关闭（控制台收起 / 弹窗关闭） | `block-chest-close-1.mp3` |
| 成功 / 成就 | `entity-firework_rocket-launch-1.mp3` |
| 出错 | `block-wooden_door-open-1.mp3` |

某个文件缺失时，只有那一个音效退回合成音，其余不受影响。
