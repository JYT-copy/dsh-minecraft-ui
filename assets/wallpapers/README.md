# 壁纸与清单（manifest）说明

仓库只自带**一张**基础壁纸：

| 文件 | 说明 |
| --- | --- |
| `cozy-cabin.webp` | 壁炉小屋，1600px 宽，主图 |
| `cozy-cabin.thumb.webp` | 480px 缩略图，选择器里用 |

它是这个插件唯一对外发布的图片素材。其余壁纸因为版权原因**不随仓库发布**。

## 想加自己的壁纸

两条路，选一条即可：

1. **在界面里上传**（推荐）：「控制台 → 画框按钮」或「设置 → Minecraft 主题 → 壁纸库 → 我的壁纸 → 上传壁纸」。
   图片会被缩到 1920px 存进浏览器 IndexedDB，不写进插件目录，也不会进 git。
   单张上限 60 MB，支持 jpg / png / webp。
2. **放进这个文件夹**（适合想多设备同步、或者图片很大）：
   把 `<slug>.webp`（1600px）和 `<slug>.thumb.webp`（480px）放进本目录，`slug` 只能用小写字母、
   数字和连字符；再在下面任一清单里加一条，`Ctrl + R` 刷新后就会出现。

## 清单文件

| 文件 | 是否提交 | 用途 |
| --- | --- | --- |
| `manifest.json` | ✅ 提交 | 公开清单，只有 `cozy-cabin` 一条 |
| `manifest.local.json` | ❌ gitignore | 你本机的私人清单，格式同上，可以写很多条 |

条目格式：

```json
{
  "photos": [
    { "slug": "cozy-cabin", "name": "壁炉小屋", "desc": "雪夜里的小木屋，炉火正旺" }
  ]
}
```

- `slug` 必须和文件名一致（`<slug>.webp` / `<slug>.thumb.webp`）；
- 清单里的顺序就是选择器里的顺序，没写进清单的 webp 会排在后面（按文件名排序）；
- 两处都不写清单也能用：目录里所有符合命名规则的 `.webp` 都会自动出现。
