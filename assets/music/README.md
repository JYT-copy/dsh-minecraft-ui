# 背景音乐文件夹（不随插件发布）

插件会读取这个目录里的音频文件，并把它们列进「设置 → Minecraft 主题 → 背景音乐 → 曲目」。

支持的扩展名：`.ogg` `.oga` `.mp3` `.m4a` `.wav` `.flac`。

## 为什么这里是空的

Minecraft 原声（C418 / Lena Raine 等）受版权保护，**不能**随这个仓库一起发布，所以仓库里只有这份说明。
想听到原声，请把你**自己拥有**的音频文件放进这个目录，然后：

1. 在 GUI 里按 `Ctrl + R` 刷新页面（清单是在页面加载时读取的）；
2. 打开「设置 → Minecraft 主题 → 背景音乐」，勾选「播放 BGM」，再从曲目列表里挑一首。

## 想自己上传（不需要碰文件夹）

「设置 → Minecraft 主题 → 背景音乐 → 我的音乐」里可以直接上传音频文件，文件存在浏览器的
IndexedDB 里，不会进入插件目录，也不会被提交到 git。单曲上限 60 MB。

## 命名建议

文件名就是列表里显示的曲名（会去掉扩展名）。如果文件名里带 `[...]` 之类的尾巴
（例如从音乐平台下载的 `C418 - Sweden [mqms2].ogg`），插件会自动去掉它。
